# umabozu

umabozuは、競走馬のレース結果を予測し、利益を生み出す賭けの機会を特定するために設計されたAIシステムです。
過去のレースデータ、馬と騎手のプロフィール、および高度な機械学習モデル (LightGBM) を活用することで、100%を超える投資収益率 (ROI) の達成を目指します。

---

## 特徴

-   **データ収集 (`update`):** netkeiba.com から過去のレース結果、馬のプロフィール、騎手のプロフィールをスクレイピングします。日付範囲の指定に対応しています。
-   **モデル学習 (`train`):** 収集したデータを用いて LightGBM 分類モデルを学習させ、最適化されたモデルを保存します。Optuna によるハイパーパラメータ最適化、train/test分割によるバックテストモードにも対応。
-   **予測/バックテスト (`predict`):** データベースに既に存在する過去のデータを分析し、賭けをシミュレーションしてROIを計算します。戦略の改善に役立ちます。
-   **シミュレーション (`simulate`):** train/test分割を行い、テストセットでのバックテスト結果（ROI、的中率、ベット数など）を詳細にレポートします。学習と評価を分離した設計。
-   **未来レース予測 (`forecast`):** netkeiba.com から開催前のレースの出馬表情報をリアルタイムで取得し、過去のデータと統合して、期待値 (EV) および勝率に基づいた賭けの推奨を提供します。
-   **プロフィールの自動同期:** 未来のレースを予測する際、データベースに存在しない新しい馬や騎手のプロフィールを自動的にネット競馬から取得し、データベースに保存します。
-   **戦略最適化:** (`tools/optimize_strategy.py` として実装) 最高のROIを得るための最適な賭けの閾値（期待値と最低勝率）を見つけるためのユーティリティです。

## セットアップ

1.  **リポジトリのクローン:**
    ```bash
    git clone https://github.com/your-username/umabozu.git
    cd umabozu
    ```

2.  **`uv` のインストール (まだインストールしていない場合):**
    `uv` は高速な Python パッケージインストーラおよびマネージャーです。
    ```bash
    pip install uv
    ```

3.  **仮想環境の作成とアクティベート:**
    ```bash
    uv venv
    .\.venv\Scripts\activate # Windows PowerShell の場合
    # source ./.venv/bin/activate # Linux/macOS の場合
    ```

4.  **依存関係のインストール:**
    ```bash
    uv pip install -e .
    ```

## 使用方法

umabozu はコマンドラインインターフェース (`cli.py`) を介して操作します。

### 1. データ更新

ローカルデータベースを netkeiba.com のデータと同期します。これにより、レース結果とプロフィールが取得されます。

-   **過去7日間のデータを更新 (デフォルト):**
    ```bash
    python cli.py update
    ```
-   **過去の特定の日数分のデータを更新:**
    ```bash
    python cli.py update --days 30
    ```
-   **特定の日付範囲のデータを更新 (例: 2022年全体):**
    ```bash
    python cli.py update --start 2022-01-01 --end 2022-12-31
    ```

### 2. モデル学習

データベース内の全ての利用可能なデータを使用して予測モデルを学習させます。このプロセスにより、`trained_models/lgbm_model.pkl` が更新されます。データを更新した後での実行を推奨します。

-   **デフォルト学習 (高速、最適化なし):**
    ```bash
    uv run cli.py train
    ```

-   **Optuna最適化を使用 (より高精度だが時間がかかる):**
    ```bash
    uv run cli.py train --optimize --n-trials 50
    ```

-   **train/test分割で評価付き学習:**
    ```bash
    uv run cli.py train --test-ratio 0.2
    ```
    *20%のデータをテストセットに分割し、学習後にパフォーマンスをログに記録します。*

### 3. バックテストシミュレーション (新機能)

学習済みモデルを使用してバックテストを実施します。train/test分割を行い、テストセットで詳細なバックテストを実施します。ROI、的中率、ベット数などの詳細なレポートが生成されます。

**推奨ワークフロー（2ステップ）:**

1. まずモデルを学習:
    ```bash
    uv run cli.py train
    ```

2. 学習済みモデルでシミュレーション（高速）:
    ```bash
    uv run cli.py simulate
    ```

**simulateコマンドのオプション:**

-   **デフォルト設定（学習済みモデル使用）:**
    ```bash
    uv run cli.py simulate
    ```

-   **カスタムテスト比率:**
    ```bash
    uv run cli.py simulate --test-ratio 0.3
    ```

-   **カスタムモデルパス:**
    ```bash
    uv run cli.py simulate --model-path trained_models/my_model.pkl
    ```

-   **その場で学習してシミュレーション（1ステップ、再学習モード）:**
    ```bash
    uv run cli.py simulate --retrain
    ```

-   **Optuna最適化を使用して学習＆シミュレーション:**
    ```bash
    uv run cli.py simulate --retrain --optimize --n-trials 30
    ```

### 4. 過去の予測

データベースに既に存在する特定の日のデータを分析します。これは、過去のイベントに対するモデルのパフォーマンスを検証するのに役立ちます。

-   **特定の日の予測 (例: 2023-01-29):**
    ```bash
    uv run cli.py predict 2023-01-29
    ```

-   **今日の予測 (デフォルト):**
    ```bash
    uv run cli.py predict
    ```

### 5. 未来レースの予測 (開催前レース)

netkeiba の12桁のレースIDを指定して、開催前のレースの賭けの推奨を取得します。システムはライブの出馬表をスクレイピングし、不足している馬/騎手のプロフィールを同期し、過去のデータを統合して推奨を提供します。

-   **特定のレースを予測 (例: 2023年シルクロードS):**
    ```bash
    uv run cli.py forecast 202305010211
    ```
    *出力には、オッズ、期待値、AI予測勝率を含む推奨馬が表示されます。*

### 6. データベースステータス確認

データベースの統計情報と欠損データ期間を確認します。

-   **週末レース (JRAモード、デフォルト):**
    ```bash
    uv run cli.py status
    ```

-   **全日レース (地方競馬モード):**
    ```bash
    uv run cli.py status --local
    ```

## 開発ツール

本プロジェクトでは、コード品質を維持するために以下のツールを使用しています。

### 1. Ruff (Lint & Format)

コードスタイルのチェックと自動整形に使用します。

-   **チェックの実行:**
    ```bash
    uv run ruff check .
    ```
-   **自動修正と整形:**
    ```bash
    uv run ruff check --fix .
    uv run ruff format .
    ```

### 2. ty (Type Check)

Astral製の高速な型チェッカを使用して、静的型チェックを行います。

-   **型チェックの実行:**
    ```bash
    uv run ty check
    ```
    *※ LightGBM などの外部ライブラリについては、型定義が不完全なため一部 `# type: ignore` や `Any` を使用しています。*

## 今後の展望 / 将来の強化
-   **データ拡充:** モデルの堅牢性を高め、過学習を防ぐために、より多くの過去データ (例: 2021年以前) を収集します。
-   **高度な特徴量エンジニアリング:** 血統データ、高度な過去成績指標 (例: 上がり3Fタイム、ペース分析)、または特定のレース条件に関する特徴量を取り込みます。
-   **リアルタイムオッズ統合:** レース直前のオッズをより正確に取得するためのライブオッズ取得機能を実装します。
-   **モデル強化:** より洗練されたモデルやアンサンブル手法を検討します。
-   **モニタリングとアラート:** モデルのパフォーマンスを時系列で監視し、重要な逸脱を警告する機能を追加します。
-   **Web UI:** より簡単な操作のためにシンプルなウェブインターフェースを開発します。
